One line, 113 characters: the funniest voicemail greeting a cat would record.

> You've reached Pickles. I'm napping in the box you threw away. Leave a message after the beep, then bring snacks.

`main.ts` writes the greeting to `$MAKEFUN_OUTPUT_DIR/entry.txt` (fallback `/output`), prints it, and self-checks it against the 120-character gate — then reads it back and re-gates the written file.

Run it:

```sh
node main.ts
```
